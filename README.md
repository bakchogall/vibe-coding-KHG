# PromptCheck

챗봇 AI가 써 준 **이미지·영상 생성용 영어 프롬프트**를 생성 AI에 넣기 전에 붙여넣으면, 각 부분의 역할과 빠진 요소·충돌하는 지시·모호한 표현을 규칙으로 점검해 주는 웹 도구입니다.

**데모: https://bakchogall.github.io/vibe-coding-KHG/** (설치 없이 브라우저에서 바로 열립니다)

## 왜 만들었나

내 의도를 챗봇에게 설명해 프롬프트를 받으면, 챗봇이 써 준 긴 프롬프트를 하나하나 읽고 분석해서 어떻게 작동할지 스스로 판단해야 합니다. 그 일이 너무 귀찮고 번거로웠고, 결국 ① 내 의도가 프롬프트에 온전히 담겼는지, ② 담겼더라도 생성 AI에서 원하는 결과가 나올지 확인하지 못한 채 "잘 써줬겠지" 하고 넘어가곤 했습니다. 단어 뜻을 몰라서 생긴 불편이 아니라, **프롬프트가 무엇을 지시하는지 쉽게 눈으로 확인할 수단이 없다**는 불편에서 출발했습니다.

## 할 수 있는 것

- **요소별 해부**: 단어와 구절을 주제, 배경/장소, 스타일, 조명, 카메라, 구도, 색, 품질/해상도, 가중치/수식어(영상은 카메라 움직임, 피사체 움직임 추가)로 나눠 색과 이름표로 보여주고, 용어마다 짧은 한국어 설명을 붙입니다.
- **경고**: 빠진 요소, 서로 충돌할 수 있는 지시(`warm tone` ↔ `cool tone` 등), 모호한 표현(`beautiful`, `maybe`), 부정 지시, 이미지용에 섞인 영상 전용 표현을 알려줍니다.
- **의도 점검**: "내가 신경 쓴 요소"를 체크하면 프롬프트에 없을 때 경고하고, "프롬프트가 이렇게 읽힌다" 표로 요소별 내용을 한눈에 비교할 수 있습니다.
- **내 용어 사전**: 사전에 없는 단어를 직접 추가·수정할 수 있습니다(이 브라우저에만 저장).
- **외부에서 찾아보기**: 사전에 없는 단어는 누를 때만 Wikipedia에서 설명을 찾아 참고용으로 보여줍니다.

## 할 수 없는 것

- 프롬프트가 생성 AI에서 **잘 작동하는지는 보장하지 못합니다.** 위험 신호를 알려 줄 뿐입니다.
- 사전과 고정된 규칙으로만 읽기 때문에, 사전에 없는 표현은 분류하지 못하거나 "빠졌다"고 잘못 안내할 수 있습니다. 한글 단어와 모델별 규칙은 분석하지 않습니다.

## 어떻게 만들었나

- 순수 HTML / CSS / JavaScript. 서버, 빌드 도구, 프레임워크, 외부 라이브러리가 없습니다.
- **AI를 쓰지 않습니다.** 분류와 경고는 용어 사전과 규칙으로만 하므로, 같은 입력은 항상 같은 결과가 나옵니다.
- 입력한 프롬프트는 서버로 보내지 않습니다. 내 사전과 조회 결과는 브라우저(localStorage)에만 저장됩니다. 다만 "외부에서 찾아보기"를 누르면 그 단어 하나가 Wikipedia(필요하면 Datamuse)로 전송됩니다.
- 키보드로 모든 기능을 쓸 수 있고, 색에만 의존하지 않도록 요소 이름표를 함께 표시하며, 휴대폰 화면에서도 쓸 수 있습니다.

## 직접 열어 보기

`index.html`을 브라우저로 열면 됩니다. 주소 끝에 `#dict`를 붙이면 용어 사전 화면이 바로 열립니다.

| 파일 | 역할 |
|---|---|
| `index.html`, `css/style.css` | 화면 |
| `js/dictionary.js` | 기본 용어 사전 |
| `js/patterns.js` | 사전에 없는 표현을 모양으로 분류하는 규칙 |
| `js/analyzer.js` | 프롬프트를 요소별로 나누는 분석 |
| `js/checks.js` | 경고 규칙 |
| `js/lookup.js` | 외부 조회(Wikipedia, Datamuse) |
| `js/userdict.js`, `js/dictpage.js` | 내 용어 사전 |
| `js/ui.js`, `js/app.js` | 화면 도우미와 분석 화면 |
| `CLAUDE.md` | 작업 규칙과 결정 기록 |
